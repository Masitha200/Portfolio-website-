Android Installation Guide

Safe & Secure

Because this APK is built locally and is not distributed through the Google Play Store, Android will display an "Unknown App" or "Blocked by Play Protect" security alert during installation.

Rest assured, the app is 100% offline, privacy-first, and completely safe. It does not access the internet, run background services, or scan/collect any personal user data.

How to Bypass & Install:

1 Open APK

Tap the downloaded .apk file in your browser's download history or files manager.

2 More Details

When the security block message appears on screen, click "More details" or the small arrow.

3 Install Anyway

Tap the "Install anyway" (or Run anyway) button to complete the installation.
