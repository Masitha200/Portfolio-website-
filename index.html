Engineering CoreBurner X11

Live Telemetry

CPU POLLING

0.25s

APP ENGINE

PyQt5

BUILD SIZE

32 MB

System Telemetry & Performance Dashboard

CoreBurner X11 was built to resolve a common problem for system enthusiasts: high-frequency hardware profiling that doesn't tank game frame rates. It aggregates low-level graphics telemetry and processor registers in real time.

The Architectural Challenge

Running high-frequency (5Hz+) system hardware scans typically blocks UI draw calls on single-thread programs. That means telemetry counters lag, causing sensor readings to stutter and skip key heat spikes.

The Engineering Solution

We decoupled sensor telemetry collection from PyQt5 repaint engines. Implementing a background caching thread using non-blocking calls (via psutil and GPUtil) allowed telemetry stats to update at 0.25 seconds without dragging interface frames.

Standalone PDF Page Organizer & Rotator

AetherPDF was built to solve common offline document manipulation issues. It provides a visual drag-and-drop page workspace (reordering, duplicating, deleting, and rotating pages of files) built entirely client-side.

The Architectural Challenge

Traditional tools rely on heavy cloud servers to process PDF pages which raises security issues and lags for large documents. Native desktop utilities require an elegant UI combined with high-speed compilation of assets without leaking document telemetry.

The Engineering Solution

We packaged React and TypeScript views within an Electron wrapper. By performing document segmentation and rendering visually using client-side rendering engines, we eliminated network overhead and guaranteed 100% offline security.
